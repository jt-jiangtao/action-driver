## 变更场景

- 模型设置：旧 SQLite 数据默认 `openai-images`；模型能力开关和默认模型引用保留。设置页可选择 Token Plan，保存后重开仍保持；非官方 HTTPS Token Plan 地址会拒绝并保留原选项。单元测试覆盖刷新，Electron 用例覆盖设置和默认模型的跨进程持久化。
- 生图接口：适配器 Mock 测试覆盖鉴权、请求格式、单张图片下载、空结果、非 HTTPS 临时链接、下载失败、大小限制、取消和超时；服务测试覆盖按模型接口路由。工具集成测试覆盖四图并发、部分失败、成功资产和临时链接不进入工具事件。
- 未配置提示：Agent 图测试覆盖每轮模型请求的动态配置说明、工具可用性变化和历史消息不累积说明。
- 图片显示：组件测试覆盖宽幅预览、文件名和移除、输入框与用户消息的放大、保存及缺失占位。Electron 用例使用 1600×600 白底文字图验证输入预览、发送后显示、重开会话显示和放大；实际截图已检查完整构图。
- 在途配置变更：暂停提供方响应后停用默认模型，服务测试确认结果被拒绝，工具不会收到成功字节。

## 测试边界

官方 Token Plan 网关只允许官方 HTTPS 域名，因此桌面测试验证设置链路，生图请求由 Mock 适配器与工具集成测试验证。未配置提示由捕获模型请求的 Agent 图测试验证，避免在桌面测试中依赖模型自由文本回复。
