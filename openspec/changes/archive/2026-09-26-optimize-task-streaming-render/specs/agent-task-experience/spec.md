## ADDED Requirements

### Requirement: 流式输出期间只重渲染变化的内容
系统 SHALL 在模型流式输出期间只重新渲染发生变化的消息、文本块、工具行与活动组；未变化的历史消息与历史轮次 MUST NOT 因新的流式增量而重新渲染或重新执行 Markdown 渲染。流式更新 MUST NOT 引起侧边栏与首页重新渲染。任务快照 SHALL 为不可变数据，分发路径 MUST NOT 修改已发出的快照。

#### Scenario: 长对话中流式输出
- **WHEN** 任务已有 100 条历史消息，最后一条助手消息持续收到文本增量
- **THEN** 只有最后一条消息重新渲染，历史消息的渲染次数不变，Markdown 只对变化的文本块重新渲染

#### Scenario: 流式更新不影响应用外壳
- **WHEN** 当前任务收到流式更新
- **THEN** 侧边栏与应用外壳不重新渲染，任务页正确显示最新内容

#### Scenario: 已发出的快照保持不变
- **WHEN** 投影在发出快照后继续处理后续事件
- **THEN** 此前发出的快照内容保持不变，新快照中未变化的部分与旧快照共享同一引用
