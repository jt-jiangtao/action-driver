## Why

用户需要把重要聊天固定在侧栏，并把已结束的聊天移出最近列表后仍能找回。目前侧栏没有置顶、归档操作，设置页没有归档入口；运行时虽有未使用的 `archived` 投影列，但状态无法通过权威日志持久化。

## What Changes

- 最近聊天行在悬停或键盘聚焦时显示置顶和归档操作；长标题仅在溢出时向左移动到末尾并停住，尊重减少动态效果偏好。
- 会话级置顶与归档状态由本地 Runtime 持久保存；置顶聊天优先排列，归档聊天从最近列表移除，运行中或排队中的聊天不能归档。
- 设置页新增“已归档的聊天”，可搜索、分页查看、打开及取消归档；操作失败保留原状态并显示错误。
- 首版不做项目分组、项目过滤、永久删除或批量删除；不新增外部依赖。

## Capabilities

### New Capabilities

- `session-organization`: 定义会话级置顶、归档、目录查询、搜索、排序、分页和恢复行为。

### Modified Capabilities

- `desktop-shell`: 扩展最近聊天行的操作与标题阅读方式，以及设置导航和归档页面。
- `rollout-persistence`: 将会话组织状态写入权威日志并允许 SQLite 投影重建。

## Impact

- 本地 Runtime 的会话日志、投影、目录仓储和 HTTP 路由；桌面端的目录适配器、侧栏、设置路由与页面。
- 扩展类型化会话目录响应和状态变更接口；现有任务打开方式保持按 task ID 工作。
- 定向测试覆盖持久化、排序、分页、失败恢复和界面可访问性。

- 类型：产品交互与数据所有权的混合决策型。
- 状态：**已完成**。用户于 2026-09-30 明确选择持久化方案，并确认书面设计。
- 最终方向：Runtime 拥有会话组织状态，Rollout JSONL 作为权威记录；桌面端提供已裁决的侧栏和设置页操作。
- 关键假设已检查：当前目录只返回任务摘要，缺少会话组织接口；现有会话摘要没有项目标识。前端临时状态无法满足重启后恢复。已比较该替代方案；无未解决的关键分歧。
