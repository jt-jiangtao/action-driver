## MODIFIED Requirements

### Requirement: 动态活动任务与有序正文

系统 SHALL 把一个 Turn 呈现为按会话追加式日志序号排列的可见块序列，而不是固定工具类别或每次 LLM 调用的卡片。可见块 MUST 包括过程正文、工具组、图片批次占位、图片与文档；每块 MUST 只有一次分配的序号。系统 MUST 对全部实际工具流建立工具组：Runtime 在工具执行前创建受控工具组、按规则确定其受控标题，并把连续工具调用及其间正文保序归属到同一组。客户端 MUST 在实时、重连和快照恢复时使用同一「折叠日志」结果，MUST NOT 另设一套顺序来源，MUST NOT 将存在工具记录的组回退为固定工具类别卡，也 MUST NOT 将累计助手正文整体置于活动时间线之前。

工具组 MUST 在遇到任意可见块时结束：除过程正文外，图片批次、图片与文档同样是边界；被边界隔开的工具调用 MUST 归入新组，没有被任何可见块隔开的连续或同轮并行工具调用 MUST 归入同一组。同一段过程正文的归属 MUST 只被决定一次：客户端 MUST NOT 让同一段文本同时出现在正文与活动归档中，也 MUST NOT 由多个展示组件各自重新推导归属。工具组与其子工具的占位和状态 MUST 来自日志折​叠，重开后位置 MUST 不变。

#### Scenario: 异构工具属于同一工作目标
- **WHEN** Agent 为同一受控任务摘要依次读取文件、搜索网页并运行命令
- **THEN** 客户端在同一个工具组中按发生顺序显示这些事件

#### Scenario: 正文位于任务之间
- **WHEN** Runtime 记录没有工具归属的可见正文
- **THEN** 客户端在相邻工具组之间将其呈现为独立正文片段

#### Scenario: 生成图片后的工具归入新组
- **WHEN** 生图批次与图片已作为可见块出现，其后又执行工具
- **THEN** 该工具进入新的工具组，不并入生图所在的工具组

#### Scenario: 同轮并行工具归入同组
- **WHEN** 同一轮模型返回多个工具调用，且其间没有可见块
- **THEN** 这些调用归入同一工具组，并按调用顺序稳定排列

#### Scenario: 普通工具流缺少显式活动更新
- **WHEN** 模型发起一个或多个外部工具调用且未提供受控组标题
- **THEN** Runtime 创建受控兜底工具组，并将该连续批次的所有工具调用显示为同一组内的平铺条目

#### Scenario: 从快照重新打开完成任务
- **WHEN** 客户端通过快照恢复包含工具调用的已完成任务
- **THEN** 页面显示原有的过程归档和最终结论，而不显示“运行中 / 运行结束”工具类别卡

#### Scenario: 刷新任务页
- **WHEN** 用户在任务页刷新 Renderer
- **THEN** 客户端按当前任务 ID 从日志折叠结果恢复任务详情、标题、消息和活动过程，不要求用户再次从侧栏点击任务；最近任务列表加载失败不应阻断详情恢复

#### Scenario: 活动组与工具行展开
- **WHEN** 用户展开包含文件读取、搜索和命令的活动任务
- **THEN** 活动标题箭头紧跟标题，活动与子工具图标及展开面板左边界对齐，工具行的展开箭头位于行尾；文件、搜索、Shell 与 Web Search 使用对应图标

#### Scenario: 完成态用时摘要
- **WHEN** 任务用时超过一分钟
- **THEN** 归档摘要按分钟和秒显示，而不是累计秒数

#### Scenario: 展开 Shell 输入输出
- **WHEN** 用户展开有可解析原始输入输出的 Shell 工具行
- **THEN** 面板以终端形式显示 `$` 命令、输出与退出码，不以 JSON 包装代替终端内容；持久化的原始 I/O 不变

#### Scenario: 过程正文不重复出现在两处
- **WHEN** 某一轮既有活动归档的过程正文，又有包含同一段文本的助手消息
- **THEN** 用户看到的该段文本只出现一次，且其归属在流式增量期间保持稳定，不出现忽隐忽现
