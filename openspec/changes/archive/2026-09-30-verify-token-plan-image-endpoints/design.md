## Context

见 `proposal.md`。现有 `ModelConnectionService` 的能力测试经 `probeCapability` 生成一张测试图，`generateImage` 则按 `baseUrl` 的域名直接选择适配器。`ModelOptionDto.imageGenerationApi` 只有接口类型，没有逐接口测试证据；当前主要持久化是 `model-connections.json`，仓库还保留 SQLite store。设置页的单项测试与“刷新并测试”最终都调用模型测试服务。

Token Plan 适配器目前只识别 `*.maas.aliyuncs.com`，实测连接使用 `token-plan.maas.qianwenaiapi.com`。官方文档的多模态生成示例也使用后者的 `/api/v1/services/aigc/multimodal-generation/generation` 路径。两个候选接口的请求格式和响应格式不同，必须用各自适配器真实生成并验证图片，不能仅以 HTTP 200 或图片 URL 为成功。

## Goals / Non-Goals

**Goals:** 让这三个已配置 Token Plan 生图模型各自拥有可追溯的接口测试结果；测试、默认模型资格和运行路由共用同一验证依据；旧记录安全降级为待验证。

**Non-Goals:** 不改变其他连接的 Images API 支持，不扩大 Token Plan 模型列表，不加入音视频请求，不改变会话图片的展示和保存流程。

## Decisions

1. **仅对指定连接与三个模型启用双接口探测。** 以受信任的 Token Plan 网关识别和模型 ID 白名单同时限定新路径，候选为兼容 `/images/generations` 与 Token Plan 多模态生成接口。扩充网关识别以覆盖当前的 `*.maas.aliyuncs.com` 和实测的 `token-plan.maas.qianwenaiapi.com`；生成接口须从已验证连接地址推导同源目标，不允许任意自定义主机借“Token Plan”路由发送密钥。其余连接仍走原有通用生图路径。替代方案是所有 OpenAI 兼容连接都双探测；它会增加无关连接的付费请求，并扩大凭据发送面，不符合裁决范围。
2. **每次显式测试逐一完成两个候选接口。** 单项模型测试、添加流程中的模型测试与“刷新并测试”共用服务端探测逻辑；该模型的两个生图接口顺序测试，即使首个成功也继续测试另一个。接口成功要求获得并完成图片下载及现有图片解码验证；每次探测不把测试图加入会话。模型间原有并发限制保留。替代方案是只请求官方文档接口；它请求更少，但不能记录兼容接口实际是否可用，也无法实现用户裁决的逐接口验证。用户已知重复实测可能消耗额度，仍选择双探测。
3. **把接口证据与模型绑定并持久化。** 为模型存储两个接口各自的 `state`、`testedAt` 和脱敏后的失败诊断，并记录本次选择的成功接口；公共 DTO 只传递诊断所需状态，不传递凭据、图片地址或字节。草稿测试结果在服务端按连接参数和模型保留一份临时证明；新增连接时只采纳这份证明，不信任页面提交的成功字段，保存后移除临时证明。新结果在两个探测结束后一起覆盖该模型旧结果，失败接口不能进入运行候选。若两个都成功，优先选择官方文档使用的 Token Plan 多模态接口，保持确定性；运行失败不自动切换。复用现有图片适配器的超时、大小、重定向和取消限制。替代方案是只存一个接口枚举；它无法区分旧人工字段与真实验证，也会丢失失败接口的诊断。
4. **把运行资格收紧到当前连接的验证证据。** `generateImage`、默认生图可用性与设置页资格使用同一模型级判断，运行时再次检查所选接口在当前模型的结果中为成功。旧 `imageGenerationApi` 或旧单项生图成功不视为证据；刷新发现保留同一模型的有效结果，重测失败则立即撤销旧成功，连接地址或凭据改变时清空相关接口结果。旧默认引用可保留供用户重测后恢复，但重测前生图工具不可用。替代方案是保留旧成功并在首次生成时试错；它可能把失败接口投入真实任务，与“只使用已验证接口”冲突。

## Risks / Trade-offs

- [一次点击可能产生两次真实生图及下载，刷新批量测试也会触发] → 沿用现有明确费用提示、同模型防重入与并发上限；这是用户已知并接受的代价。
- [提供方返回 URL 但图片下载失败] → 该接口判为失败并保留脱敏诊断，不把 HTTP 200 当作成功；此前实测只证明接口返回了图片地址，尚未证明下载与解码成功。
- [两个接口都可用，或重测时提供方状态波动] → 固定 Token Plan 多模态接口优先级；只按最近一次完整测试结果选择，失败时不尝试未验证回退。
- [旧配置升级后暂时不能生图] → 保留连接与默认模型引用、呈现待测试状态，让用户显式重测；不会用旧字段绕过新验证门槛。
- [提供方错误或响应含敏感数据] → 仅保存和返回经过现有密钥脱敏规则处理的短诊断，不持久化原始响应、图片 URL、图片字节或明文密钥。

## Migration Plan

读取旧模型记录时把缺失的新接口结果视为未测试；不根据旧 `imageGenerationApi` 推断成功。写入新的模型级结果时保持旧连接 ID、模型 ID、启用状态和默认引用。实现时同步覆盖当前文件 store 与仓库保留的 SQLite store 对该字段的读写，确保服务使用任一 store 时不丢失证据。回滚时旧版本忽略新增字段，但可能沿用旧路由；因此回滚属于恢复旧行为，不应被视为继续满足本变更的验证约束。
