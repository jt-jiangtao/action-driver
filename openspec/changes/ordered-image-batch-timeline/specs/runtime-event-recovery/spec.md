## MODIFIED Requirements

### Requirement: 重放与快照恢复保持一致
系统 SHALL 按请求和 cursor 有界重放已提交事件，并 SHALL 在重放缺口不可恢复时提供同一高水位的状态快照；客户端 MUST 忽略重复事件，按请求序号连续应用后才推进已应用水位。生图批次位置 MUST 在工具开始时与助手内容原子持久化，并 SHALL 在其图片结果之前进入可重放事件；重放和快照 MUST 保持同一批次与文字顺序。

#### Scenario: 重连时遇到乱序和重复事件
- **WHEN** 客户端收到重复帧、乱序帧和其他请求交错的帧
- **THEN** 每个请求的过程文本、工具条目与终态恰好投影一次，顺序与持久化结果一致

#### Scenario: 重放范围已过期
- **WHEN** 客户端请求的事件早于服务端保留范围
- **THEN** 客户端以一致快照替换旧投影，仅应用快照水位之后的新事件

#### Scenario: 批次开始后断线
- **WHEN** 生图调用已经开始并持久化批次位置，但图片尚未全部完成时客户端断线
- **THEN** 重放或快照恢复同一批次位置与插槽数量，后续图片只更新原索引，重连不重新执行生图调用

#### Scenario: 批次位置持久化失败
- **WHEN** 批次位置和对应事件的写入事务失败
- **THEN** 客户端不收到孤立的批次事件，助手消息与事件水位均不推进
