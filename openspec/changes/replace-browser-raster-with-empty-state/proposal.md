## Why

任务页在没有真实 Browser 会话时仍展示酒店网页截图和目标高亮，容易让用户误以为 Agent 正在操作该网页；这张 1,823,683 字节的图片也进入桌面渲染产物。用户已决定取消图片占位，保留浏览器区域并按真实会话状态展示内容。

## What Changes

- 没有真实 Browser 会话时，浏览器区域在分栏和放大布局中都显示现有空状态，不再展示静态网页栅格与目标高亮。
- 有内嵌或外部 Chrome 会话时，继续使用现有真实会话展示逻辑，不改变会话控制、布局切换和 IPC 契约。
- 删除不再使用的酒店截图资产与对应样式，更新相关组件测试和视觉验收基准。

Battle 已完成：比较过保留区域显示空状态与会话建立前隐藏区域两种方案。用户裁决选择前者，以保持任务页布局和浏览器入口稳定；主要代价是旧 Mock 场景失去酒店网页示例画面。无未裁决分歧。此前的图片压缩方向已撤销。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `agent-task-experience`: 将无真实浏览器会话的静态网页占位与目标高亮改为空状态，保留三种浏览器布局与控制状态。

## Impact

涉及桌面渲染层的 BrowserPanel、浏览器样式、酒店截图资产、Mock 投影与相关测试和截图基准。无需新增依赖；不改变主进程、preload、公共数据契约或真实浏览器会话。
