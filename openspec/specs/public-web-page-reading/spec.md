# 公开网页读取规范

## Purpose

让 Agent 在搜索到公开网页或收到用户提供的 URL 后，能够读取可归因的静态页面正文，同时阻止工具访问本机及内网服务，并控制网页内容占用的网络、内存和模型上下文资源。

## Requirements

### Requirement: 读取单个公开网页
系统 SHALL 提供版本化 `web.open@1` 工具，模型名称为 `web_open`，接受一个 HTTP(S) URL，并在同一工具调用中返回该页面的标题、提取出的正文文本、最终访问 URL 和截断标记。工具 MUST NOT 自动访问正文中的链接、执行页面脚本或加载页面子资源。

#### Scenario: 读取静态页面
- **WHEN** 模型使用有效的公网 URL 调用 `web_open`，且服务返回可读取的 HTML 页面
- **THEN** 系统将非空标题或可读的标题回退值、正文文本、最终 URL 和截断标记关联到该调用，并将结果交回模型

#### Scenario: 页面依赖脚本生成内容
- **WHEN** HTML 文档没有可提取的正文，正文只能在执行 JavaScript 后出现
- **THEN** 系统返回明确的空正文或不可读取错误，不执行脚本，也不虚构网页内容

### Requirement: 限制出站网络目标
系统 MUST 只访问公网 HTTP(S) 地址。系统 MUST 拒绝 URL 凭据、本机、内网、链路本地、保留及其他非公网 IP；对主机名解析、实际连接目标和每一次重定向 MUST 重新应用该规则，并防止校验地址与实际连接地址不一致。系统 MUST NOT 携带用户 Cookie、认证凭据或环境代理凭据。

#### Scenario: URL 指向本地或内网
- **WHEN** 输入 URL 的主机是 `localhost`、私有 IP、IPv4 映射的私有 IPv6 地址，或解析到非公网地址
- **THEN** 工具在向该目标建立连接前拒绝调用，并返回可识别的访问限制错误

#### Scenario: 公网地址重定向到内网
- **WHEN** 公网响应的重定向目标是本机、内网或非 HTTP(S) URL
- **THEN** 工具拒绝跟随该跳转，不向目标建立连接

#### Scenario: DNS 地址在校验后发生变化
- **WHEN** 主机名的后续解析结果与预先校验时不同
- **THEN** 实际连接仍仅使用已校验的公网地址，或者拒绝请求，不连接新出现的非公网地址

### Requirement: 限制读取资源并提供明确失败
系统 MUST 限制单次调用的重定向次数、网络和解压后的响应字节数、正文输出长度及总执行时间，并响应取消。非成功 HTTP 状态、非 HTML 内容、无法解析的响应、资源超限和超时 MUST 返回明确错误，且 MUST NOT 将原始 HTML、响应头或不受限正文放入模型工具结果。

#### Scenario: 响应过大
- **WHEN** 页面传输或解压后的内容超过上限
- **THEN** 系统停止读取，释放连接并返回资源超限错误，不交付部分原始 HTML

#### Scenario: 正文过长
- **WHEN** 页面正文可提取但超过工具输出上限
- **THEN** 系统仅返回上限以内的正文，并将截断标记设为 true

#### Scenario: 取消正在读取的页面
- **WHEN** 用户在 `web_open` 正在连接或读取时取消任务
- **THEN** 工具停止网络读取，并按现有工具生命周期记录取消终态

### Requirement: 展示来源和工具状态
系统 SHALL 在任务活动中使用可读标题区分网页读取的准备、运行、完成和失败状态，并在可展开的工具结果中展示页面标题、来源 URL 与正文文本，而不是仅展示原始 JSON。网页正文 MUST 作为不可信外部数据处理，不得被当作 Agent 的指令或系统提示。

#### Scenario: 查看已读取页面
- **WHEN** 用户展开已完成的 `web_open` 工具行
- **THEN** 界面展示网页标题、最终来源 URL、可读正文和截断状态，并保持与任务归档一致

#### Scenario: 页面含指令样式文本
- **WHEN** 页面正文中出现要求 Agent 忽略现有规则的语句
- **THEN** 该语句仅作为来源网页的正文交付，不改变工具权限或系统提示
