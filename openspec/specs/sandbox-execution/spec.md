# sandbox-execution Specification

## Purpose

定义本地执行工具的时间、输出和运行时路径边界，确保命令与脚本在工作区内启动，并在超时或输出超限时给出明确结果。通用命令与脚本可以按用户授权读写文件和访问网络。

## Requirements

### Requirement: 限制执行资源和环境
执行工具 MUST 为子进程设置最大执行时间与最大输出字节数，并以当前会话的工作目录为默认工作目录；Python 和 Node 解释器路径及通用 Shell 可见的随包工具路径 MUST 从当前应用包确定。Shell、Python、Node 和 TypeScript 脚本及其子进程 MUST 在 macOS 每会话执行沙箱内运行，只能读取当前会话工作目录与必要的系统、应用运行时文件，不能读取或修改其他会话目录、应用私有资源及凭据。执行环境 MUST 不包含 Runtime 服务令牌、模型凭据或其他应用秘密，且 MUST 不能调用可返回其他会话数据的本地 Runtime 接口。沙箱建立失败或不可用时 MUST 拒绝执行并给出明确错误，不得退回无隔离运行。

#### Scenario: 命令输出超过上限
- **WHEN** stdout 或 stderr 超过配置上限
- **THEN** Runtime 停止继续收集、终止进程树，并以输出超限错误和已收集的受限内容结束调用

#### Scenario: 命令超过执行时间
- **WHEN** 子进程超过配置的最大时长
- **THEN** Runtime 终止进程树并以超时错误结束调用

#### Scenario: 工作区与随包路径
- **WHEN** 四种脚本执行工具启动子进程
- **THEN** 默认工作目录为当前会话工作目录，Shell 可找到随包的 `rg`、Python 与 Node，Python/Node 专用工具只使用包内解释器

#### Scenario: 跨会话与应用私有文件
- **WHEN** 当前会话的脚本或其子进程按路径尝试读取另一会话的输入、输出、历史副本或应用私有数据库
- **THEN** 系统拒绝读取且不返回文件字节；本会话 `input/` 和 `output/` 仍按权限可用

#### Scenario: 本地接口和秘密
- **WHEN** 脚本检查环境变量、尝试读取服务凭据或调用本地 Runtime 接口获取其他会话文件
- **THEN** 秘密不可得且跨会话接口访问被拒绝

#### Scenario: 沙箱不可用
- **WHEN** 操作系统无法建立本轮执行沙箱
- **THEN** 工具以明确的隔离错误结束，不启动未受限的脚本

### Requirement: Runtime 代读文件遵守会话边界
任何允许 Agent 提供文件路径或文件标识、并由 Runtime 代为读取的工具 MUST 使用可信任务与会话上下文检查归属；不得仅凭模型提交的路径或会话标识访问其他会话目录、应用私有资产和历史成品副本。需要读取本机其他位置的文件时 MUST 经用户明确选取或另行授权后纳入当前会话边界。

#### Scenario: 本地 Skill 安装路径指向其他会话
- **WHEN** 会话 B 的任务要求安装位于会话 A 工作目录中的 Skill
- **THEN** Runtime 在读取文件前拒绝该路径，不把 Skill 内容返回或安装为共享 Skill

#### Scenario: 当前会话允许的文件
- **WHEN** 工具按当前会话标识读取本会话允许的文件
- **THEN** Runtime 正常返回内容或执行获准操作，历史会话文件不受影响
